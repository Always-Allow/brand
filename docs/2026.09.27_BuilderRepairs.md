# Image builder repairs

September 27, 2026. Repairs for the four carried-forward items in [the recovered review audit](2026.09.27_LegacyReviewFindings.md).

## Changes

- Wordmark: compare each emitted path with the source in addition to existing length, transform, colour and source-hash checks.
- Avatar: read the emitted viewBox, tile dimensions/radius and transform, compare them with the source-derived values, and use the emitted scale for crop clearance.
- Banner: use a private Chrome process and wait for the embedded font and images before capture. The capture has a 20-second deadline and cleans up its private profile. Existing layout checks still run before publishing.
- Raster: render into a temporary directory on the destination filesystem, validate size and coverage, then atomically replace the destination. Check mode uses exact byte equality, with no pixel tolerance.

The additional `visual/logos/build/capture-ready-page.mjs` helper uses Chrome's debugging pipe, so it does not open a network debugging port. It requires Node and Chrome, as the builders already do, and adds no package dependency.
