## Additional mismatch found in the same exporter

The private library's raster `check()` still accepts channel differences up to `TOL = 8`. This conflicts with the documented byte-for-byte rule. The banner check already compares bytes. Restore strict byte comparison in the raster check as part of the exporter repair; do not change the approved raster rule to fit stale code.
