## Visual system

Always Allow has one light theme. Canvas is the floor. Bone is a surface. Petrol is the only
accent and is used as a fill behind canvas or bone type, or as a translucent marker under ink
type. Petrol is not a text color. Muted text is used only on canvas because it fails contrast on
bone.

| Role | Value | Use |
|---|---:|---|
| Canvas | `#FEFDFB` | Every page and slide floor |
| Bone | `#F0ECE6` | Cards, bands, chips |
| Bone deep | `#E7E0D4` | Deeper bone accents |
| Hairline | `#E3DDD2` | Borders and rules |
| Ink | `#344650` | Text |
| Muted | `#427294` | Secondary text on canvas only |
| Petrol | `#1D5372` | Accent fill or marker, never text |
| Chip gold | `#F3E5C2` | Warning and scheduled chips |

Inter is the working face for body, UI, labels, and navigation. DM Serif Display is for display
headlines only. Use no more than three heading levels. Monospace is reserved for a skill rendered
as a slash command on a pale Petrol chip.

Depth carries meaning. Always Allow objects sit on a hairline. Vendor objects float on a shadow.
Use the three shadow tokens exactly; never add a decorative fourth shadow.

## Composition grammar

- Use a generous canvas floor and an asymmetrical field, with content aligned to a simple grid.
- Use a soft Petrol wash with no visible rectangular edge.
- Use a translucent Petrol marker behind one short phrase, not a filled headline.
- Use hairline rules and open space before adding boxes.
- Use the keycap, tool tile, vendor artifact, status chip, connector, and approved glyph field as
  the reusable visual vocabulary.
- Vendor color belongs on the edge of a white vendor card. Always Allow surfaces stay in the
  Always Allow palette.
- Copy canonical workflow artifacts from `/artifacts`; do not redraw a component that exists.
- Footer on internal workshop material: `AlwaysAllow.com` left and
  `Do not distribute or reproduce` right.
- Signature block: label, title, rule, with the mark at the rule's right end. Margin is 8% of the
  short edge.

## What not to introduce

No dark surfaces, pure-white page floor, black text, second accent, unrelated pastel card sets,
new texture, mascot, illustration style, visual metaphor, isometric workflow tilt, glass on
cards, or decorative shadow. Do not use an old deck, an old Notion cover, or a favicon as a color
source.

## Distribution

The repository is the source. Google Drive carries the downloadable ZIP, PDF, and editable HTML
exports. Canva carries the editable presentation and US Letter imports. Notion's Assets database
is the directory that points people to the correct source and download.

The download ZIP includes the logo system, fonts, tokens, guides, current platform graphics,
tool-icon library, deck template, one-pager template, and visual-elements library. Date-stamped
exports are snapshots; builders and this guide explain how to regenerate them.
