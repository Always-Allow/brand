The category covers are 2400x800 so they work as both page covers and gallery-card images. The
team cover is 2400x460. Notion crops page covers to a shallow band, so the important type stays
inside the center safe area. The Strategy cover is generated by
`2026.09.03_StrategyCoverBuild.mjs`; run the builder with `--check` to verify the SVG and PNG.

## September 2 working set

The consolidation also recovered a separate light cover and page-icon set from the brand
worktree. It includes Team, Brand, Content, CRM, Ops, Stickers, and Assets, each with SVG and
PNG files. Covers are named `2026.09.02_AlwaysAllow_NotionCover_[Section]`; page icons use
`2026.09.02_AlwaysAllow_NotionPageIcon_[Section]`.

Its source is `2026.09.02_NotionAssetsBuild.mjs`. The working README described this set as a
replacement for the September 1 covers, but the current website repository still includes
the earlier set. Both are preserved while the live Notion assets and the delivered kit are
reconciled. Their presence here does not establish which set is currently installed.
