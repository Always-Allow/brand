# Platforms

Always Allow branding as it is deployed on each outside platform: the profile
pictures, covers, banners and themes that live on someone else's product.

This is not the logo set. `brand/logos/` holds the source logos
and icons, the ones you reach for when making something new. This folder holds
what is currently live on a given account, at that platform's own sizes, so that
when a platform is re-skinned you can see what it is replacing. `[2026-09-02]` Copies of
old-brand files are no longer kept here, on Sarah's call; a README says what the account shows.
`[2026-09-02, later]` The folder also holds files built for an account at that platform's checked
sizes and not yet uploaded, as the Etsy and Mercury folders do today; each platform's README says
which of its files are live and which are waiting to go up.

One folder per platform, named for the platform. A folder can be empty: it is
recorded here because the account exists and will need branding, not because a
file is ready.

Each folder's `README.md` carries that platform's size requirements and says
when they were last checked against the platform's own guidance. A size with no
checked date is a size nobody has verified, and it does not go in.
