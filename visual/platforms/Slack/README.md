# Slack

The workspace icon and the sidebar theme, built by `../build-social-assets.py`.
Filed 2026-09-01 with that builder.

The pipeline agent's profile picture, built by `2026.09.25_PipelineAgentAvatarBuild.py`
beside it. The pipeline agent is the Slack app that posts form responses, contact form
leads, nominations and sign-ups. Its picture is one brushed spiral stroke in bone on a
Petrol tile, full bleed because Slack rounds the corners itself. Sarah chose it on
2026-09-25 from the review page linked in the builder, after three rejected rounds.
Built 2026-09-25; the README says here when it goes up: not uploaded yet.

## Decided

The sidebar theme is the bone one, her choice on 2026-08-31. A Petrol variant
exists and is recorded, but a Petrol sidebar is a dark treatment and the
2026-08-24 ruling forbids those.

Petrol is never used as text, only as a fill behind bone type or a marker under
ink type. Muted `#427294` never sits on bone: it measures 4.39:1 and fails.
